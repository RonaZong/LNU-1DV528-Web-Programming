About the course literature.

Online resources are available and detailed out in each part/lesson of the course and published on the course website.

During the course we will use The Mozilla Developers Network as a guide and reference. You can see an overview of the content at "[Web technology for developers](https://developer.mozilla.org/en-US/docs/Web)".

We will use the [documentation from Node.js API](https://nodejs.org/en/docs/) as a valuable resource when developing in the Node environment.

We will use the [documentation from Express API](https://expressjs.com/en/4x/api.html) when working with that web framework.

The author Dr. Axel Rauschmayer has a [set of JavaScript online books](https://exploringjs.com/) that are most valuable for anyone learning JavaScript. The following books are relevant to this course.

* [Exploring ES2018 and ES2019](https://exploringjs.com/es2018-es2019/index.html)
* [Exploring ES2016 and ES2017](https://exploringjs.com/es2016-es2017.html)
* [Exploring ES6](https://exploringjs.com/es6.html)

The free online book "[Eloquent JavaScript](https://eloquentjavascript.net/)" provides in insight into programming in general and JavaScript in particular.
