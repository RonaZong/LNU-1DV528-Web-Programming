## Read & Study

Read and study the following, to learn about web servers.

* Quickly review [the Apache HTTP server project](https://httpd.apache.org/ABOUT_APACHE.html)
* Read about "[What is NGINX? How different is it from Apache (for example)?](https://www.nginx.com/faq/what-is-nginx-how-different-is-it-from-e-g-apache/)".
* Quickly review, or read in depth, "[How To Create a Web Server in Node.js with the HTTP Module](https://www.digitalocean.com/community/tutorials/how-to-create-a-web-server-in-node-js-with-the-http-module)".
