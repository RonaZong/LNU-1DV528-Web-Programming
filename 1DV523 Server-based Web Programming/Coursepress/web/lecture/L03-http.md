## Read & Study

Read and study the following.

* First of all read this introduction "[Learning object HTTP](https://github.com/CS-LNU-Learning-Objects/http/blob/master/http.md)"

* Quickly glance through the "[RFC 2616: Hypertext Transfer Protocol -- HTTP/1.1](https://tools.ietf.org/html/rfc2616)". At the bottom of the author list you will find T. Berners-Lee. This is how standards work on Internet.

* Read the short article "[Learning object HTTP/2](https://github.com/CS-LNU-Learning-Objects/http/blob/master/http_2.md)" to update yourself upon what HTTP/2 means.

* Read this is a small article which gives a good view of the [cache options in HTTP](https://www.mnot.net/cache_docs/).

* Extra reading to dig deeper into HTTP and how to use it - read the online book "[HTTP Succinctly](http://code.tutsplus.com/series/http-succinctly--net-33683)". Check up the following chapters.
    * HTTP Resources
    * HTTP Messages
    * HTTP Connections
    * HTTP Web Architecture
    * HTTP State and Security

* Extra viewing the video "[Yesterday's perf best-practices are today's HTTP/2 anti-patterns - Velocity 2015 (Santa Clara)](https://www.youtube.com/embed/yURLTwZ3ehk)" that provides insights into the isses that HTTP/2 is trying to solve.
