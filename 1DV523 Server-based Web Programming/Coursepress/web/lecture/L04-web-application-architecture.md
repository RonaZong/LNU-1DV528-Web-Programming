## Read & Study

Read and study the following.

* Check out the [Express website](https://expressjs.com/) och orient yourself on its resources. Do look up the API reference and see the features of the framework.

* Read up on template engines and what the [most common usage are for Express](https://expressjs.com/en/guide/using-template-engines.html).

* Read up on the templating system [Handlebars](https://handlebarsjs.com/), check it up and make your own choice of view and templating system.

* Extra viewing the conference talk with Ted Neward, on "[Modern web architecture](https://www.youtube.com/watch?v=7ujN5hwhfrs)" from Devoxx Poland 2015. A presentation of web architecture history and where we are today.
