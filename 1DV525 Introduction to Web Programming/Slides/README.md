# Slideshows

These are slideshows built using HTML, CSS, JavaScript and Markdown.

You may clone this repo and open each presentation in a web browser to view it.



### User interface

Press `f` for fullscren, leave by `esc`.

Navigate using arrow keys.

Change style by pressing `1`, `2` or `3`.
