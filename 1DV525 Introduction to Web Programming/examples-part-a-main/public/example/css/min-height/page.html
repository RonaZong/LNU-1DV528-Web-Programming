Minimum height of a page

When you have pages of different heights, depending on whether some pages have more or less content, it is a good idea to always set a minimum height on a page. It simply looks better if all pages, regardless of content, have a reasonable height.

It's easily done with CSS and one way to do it is to set 'min-height' on the element that contains the page's main content itself.

main {
    min-height: 30em;
}

The measurement 'em' corresponds to the size of a character and in the initial state it is 16 pixels large, but you can also see '20em' as 20 lines of text.
