Common elements in a HTML form.

<input type=text value=text> Text input field.
<input type=password value=password>
<input type=submit value=send> Submit button to send the form.
<button type=submit>send</button> Another type of button.
<input type=checkbox checked>
<input type=checkbox>
Check many options.
<input type=radio name=radio1 checked>
<input type=radio name=radio1>		 Check only one option.
<input type=file> Choose a file and upload it to the webserver.
<input type=image alt=submit> A image as a submit button.
<input type=reset value=reset> Retore the form to its original content.
<input type=button value=button> A button, use it to connect to its click event.
<input type=hidden value=invisible> Hidden data, not visible but sent as part of the form.
