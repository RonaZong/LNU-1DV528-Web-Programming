A HTML GET form

This form is a "self-submitting" form and it uses the method GET to submit the form through the querystring.

Changing the method to POST would send the form data through the HTTP body, instead of the querystring.

To make it fully work you need code on the webserver to take care of the submitted form, or use JavaScript in the browser to capture the submit event.
